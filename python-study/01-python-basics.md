# 파이썬 왕초보 문법 (반복문 포함)

파이썬을 처음 배우는 사람을 위한 문서. 특정 프로젝트 코드는 잊고,
**일상적인 예시**로만 설명한다.

읽으면서 직접 타이핑해보는 걸 권장한다. 터미널에서 `python`(또는 `python3`)을 실행하면
한 줄씩 입력하고 결과를 바로 볼 수 있는 대화형 모드가 켜진다.

---

## 1. 가장 기본: `print()`로 화면에 출력하기

```python
print("안녕하세요")
```
실행 결과:
```
안녕하세요
```

`print()`는 괄호 안의 내용을 화면에 보여주는 명령이다. 이게 전부다.

---

## 2. 변수 — 값에 이름 붙이기

```python
name = "철수"
age = 30
print(name)
print(age)
```
실행 결과:
```
철수
30
```

`name = "철수"`는 "`name`이라는 이름표를 `"철수"`라는 값에 붙인다"는 뜻이다. 이후 `name`을 쓰면 `"철수"`를 쓴 것과 같다.

- 문자열(글자)은 `" "` 또는 `' '`로 감싼다: `"철수"`
- 숫자는 그냥 쓴다: `30` (따옴표 없음)

값을 바꾸고 싶으면 다시 대입하면 된다:
```python
age = 30
print(age)   # 30
age = 31
print(age)   # 31
```

---

## 3. 숫자 계산

```python
a = 3
b = 5
print(a + b)   # 8
print(a * b)   # 15
print(b - a)   # 2
print(b / a)   # 1.6666...
print(b % a)   # 2  (나머지)
```

`%`는 나눗셈의 **나머지**를 구하는 연산자. 예: `5 % 3`은 5를 3으로 나눈 나머지인 2.

---

## 4. 조건문 `if` — 조건에 따라 다르게 동작

```python
age = 20

if age >= 18:
    print("성인입니다")
else:
    print("미성년자입니다")
```
실행 결과:
```
성인입니다
```

- `if 조건:` 다음 줄부터, **들여쓰기(스페이스 4칸)**된 부분이 "조건이 참일 때 실행되는 코드"
- `else:`는 "그 조건이 거짓일 때" 실행되는 코드
- 조건이 여러 개면 `elif`(else if의 줄임)를 추가:

```python
score = 75

if score >= 90:
    print("A학점")
elif score >= 80:
    print("B학점")
elif score >= 70:
    print("C학점")
else:
    print("D학점")
```
실행 결과:
```
C학점
```
위에서부터 순서대로 조건을 검사하다가, 처음으로 참인 조건에서 멈추고 그 블록만 실행한다.

## 5. 반복문 `for` — 같은 동작을 여러 번 반복

### 5-1. 가장 단순한 형태: `range()`로 N번 반복

```python
for i in range(5):
    print(i)
```
실행 결과:
```
0
1
2
3
4
```

- `range(5)`는 `0, 1, 2, 3, 4` 다섯 개의 숫자를 순서대로 만들어내는 장치 (5는 포함 안 됨! "5개"를 만든다는 뜻)
- `for i in range(5):`는 "`range(5)`가 만드는 숫자를 하나씩 꺼내서, 그때마다 `i`라는 이름에 넣고, 아래 들여쓰기된 코드를 실행"
- 즉 아래 코드가 **5번 반복 실행**되고, 매번 `i` 값만 0→1→2→3→4로 바뀐다

**비유**: `for i in range(5):`는 "i를 0부터 4까지 바꿔가면서, 아래 코드를 그때마다 한 번씩 실행해" 라는 뜻.

### 5-2. 실용 예시 — 구구단 2단

```python
for i in range(1, 10):     # 1부터 9까지 (10은 미포함)
    print("2 x", i, "=", 2 * i)
```
실행 결과:
```
2 x 1 = 2
2 x 2 = 4
2 x 3 = 6
...
2 x 9 = 18
```

`range(1, 10)`처럼 시작값을 지정할 수도 있다. `range(시작, 끝)`은 "시작부터 끝-1까지".

### 5-3. 리스트를 순회하기

리스트는 여러 값을 순서대로 담는 그릇이다 (`3-1`절 참고). `for`로 리스트 안의 값들을 하나씩 꺼내 쓸 수 있다.

```python
fruits = ["사과", "바나나", "포도"]

for fruit in fruits:
    print(fruit, "좋아해요")
```
실행 결과:
```
사과 좋아해요
바나나 좋아해요
포도 좋아해요
```

`for fruit in fruits:`는 "`fruits` 리스트에서 값을 하나씩 꺼내서 `fruit`이라는 이름에 넣고 반복"이라는 뜻. `range()`와 원리는 완전히 같다 — 그냥 "숫자 0,1,2,3,4" 대신 "리스트 안의 실제 값들"을 순서대로 꺼내는 것뿐.

### 5-4. 반복 중 조건과 같이 쓰기 (합계 구하기)

```python
numbers = [10, 25, 3, 47, 8]
total = 0

for n in numbers:
    total = total + n

print("합계:", total)
```
실행 결과:
```
합계: 93
```

`total = total + n`은 "지금까지의 total에 n을 더한 걸 다시 total에 저장"이라는 뜻. 반복할 때마다 total이 누적된다. (짧게 `total += n`이라고도 쓴다. 완전히 같은 뜻.)

### 5-5. 반복 중 조건문 함께 쓰기 (짝수만 출력)

```python
for i in range(1, 11):
    if i % 2 == 0:
        print(i, "은(는) 짝수")
```
실행 결과:
```
2 은(는) 짝수
4 은(는) 짝수
6 은(는) 짝수
8 은(는) 짝수
10 은(는) 짝수
```

`i % 2 == 0`은 "i를 2로 나눈 나머지가 0이다" = "i가 짝수다". `==`는 "같다"를 비교하는 연산자 (대입하는 `=`와 다름! 헷갈리지 않도록 주의).

`for` 안에 `if`가 들여쓰기 한 단계 더 들어가 있는 걸 주목. **들여쓰기 깊이 = 어느 블록에 속하는지**를 나타낸다.

## 6. 반복문 `while` — 조건이 참인 동안 계속 반복

`for`가 "정해진 횟수만큼" 반복이라면, `while`은 "조건이 거짓이 될 때까지" 반복한다.

```python
count = 0

while count < 5:
    print(count)
    count = count + 1
```
실행 결과:
```
0
1
2
3
4
```

동작 순서:
1. `count < 5`가 참인지 검사 (처음엔 count=0이라 참)
2. 참이면 블록 실행 (`print`, `count` 증가)
3. 다시 1번으로 돌아가서 검사
4. `count`가 5가 되는 순간 조건이 거짓이 되어 반복 종료

**주의**: `count = count + 1`을 빠뜨리면 조건이 영원히 참이라 무한 루프에 빠진다. `while`을 쓸 때는 "언젠가 조건이 거짓이 될 방법"이 코드 안에 반드시 있어야 한다.

**`for` vs `while` 어떻게 고르나**: "몇 번 반복할지" 또는 "무엇을 순회할지"가 명확하면 `for`, "언제 멈출지 조건으로만 정해져 있으면"(반복 횟수를 미리 모름) `while`.

---

## 7. 반복 중간에 멈추거나 건너뛰기 — `break`, `continue`

```python
for i in range(10):
    if i == 5:
        break          # 반복문을 즉시 통째로 종료
    print(i)
```
실행 결과:
```
0
1
2
3
4
```
`i`가 5가 되는 순간 `break`를 만나 반복 자체가 끝나버린다 (5, 6, 7...은 아예 실행 안 됨).

```python
for i in range(5):
    if i == 2:
        continue        # 이번 반복만 건너뛰고 다음 반복으로
    print(i)
```
실행 결과:
```
0
1
3
4
```
`i`가 2일 때만 `print(i)`를 건너뛰고, 반복 자체는 계속된다.

## 8. 함수 — 반복해서 쓸 코드를 이름 붙여 저장

```python
def greet(name):
    print(name, "님 안녕하세요")

greet("철수")
greet("영희")
```
실행 결과:
```
철수 님 안녕하세요
영희 님 안녕하세요
```

- `def 함수이름(매개변수):` 로 함수를 "정의"만 해두고, `greet("철수")`처럼 **호출**해야 실제로 실행된다.
- 매개변수(`name`)는 호출할 때 넘겨준 값(`"철수"`)이 들어가는 자리.

값을 돌려받고 싶으면 `return`:
```python
def add(a, b):
    return a + b

result = add(3, 4)
print(result)   # 7
```
`return`을 만나면 함수는 그 값을 돌려주고 즉시 끝난다.

**함수 안에서 반복문을 쓰는 예시** (지금까지 배운 걸 합친 것):
```python
def sum_up_to(n):
    total = 0
    for i in range(1, n + 1):
        total = total + i
    return total

print(sum_up_to(5))    # 1+2+3+4+5 = 15
```
실행 결과:
```
15
```
