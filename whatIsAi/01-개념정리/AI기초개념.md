# AI / LLM 기초 개념 정리

## 1. 인공지능(AI) 계층 구조

```
AI (인공지능)
 └─ Machine Learning (머신러닝)
     └─ Deep Learning (딥러닝)
         └─ LLM (대규모 언어모델)
```

- **AI**: 인간의 지능적 행동(학습, 추론, 판단)을 컴퓨터로 구현하려는 포괄적 개념
- **머신러닝**: 규칙을 사람이 직접 코딩하지 않고, 데이터에서 패턴을 학습시키는 방식
- **딥러닝**: 머신러닝 중에서도 인공신경망(뉴런을 본뜬 구조)을 여러 층 쌓아 학습하는 방식
- **LLM**: 딥러닝 중에서도 방대한 텍스트 데이터로 학습해 언어를 이해/생성하는 모델 (예: GPT, Claude)

## 2. 인공신경망(Neural Network)이란

- 입력값 → 여러 층(layer)을 거치며 숫자 연산 → 출력값
- 각 층은 "가중치(weight)"를 가지고 있고, 학습이란 이 가중치를 데이터에 맞게 조정하는 과정
- 비유: 처음엔 무작위로 추측하다가, 정답과 비교해서 틀린 만큼 가중치를 조금씩 고쳐나감 (역전파, backpropagation)

## 3. 토큰(Token)과 토큰화(Tokenization)

- LLM은 문장을 통째로 이해하지 않고, "토큰"이라는 작은 단위로 쪼개서 처리
- 토큰은 단어일 수도, 단어의 일부(subword)일 수도, 글자 하나일 수도 있음
- 예: "안녕하세요" → ["안녕", "하세요"] 또는 더 잘게 쪼개질 수 있음
- 모델은 각 토큰을 숫자 벡터(embedding)로 변환해서 연산에 사용

## 4. 트랜스포머(Transformer)와 어텐션(Attention)

- 2017년 "Attention Is All You Need" 논문에서 제안된 구조. 현재 모든 LLM의 기반
- 핵심 아이디어: **어텐션(Attention)** — 문장 안에서 각 단어가 다른 단어들을 "얼마나 참고해야 하는지" 가중치를 계산
  - 예: "그 강아지는 밥을 먹고 나서 **그것을** 좋아했다" → "그것을"이 "밥"을 가리키는지 파악하려면 문장 전체를 참고해야 함. 어텐션이 이런 연관성을 계산
- **셀프 어텐션(Self-Attention)**: 문장 내 모든 토큰 쌍 사이의 연관도를 계산하는 방식
- 트랜스포머는 이 어텐션 구조를 여러 층 쌓아서 문맥을 이해

## 5. 언어모델의 학습 방식: "다음 단어 예측"

- LLM 학습의 본질은 단순함: **주어진 텍스트 다음에 올 단어(토큰)를 맞히는 것**
- 예: "오늘 날씨가 정말" 다음에 올 확률이 높은 단어는? → "좋다", "덥다" 등
- 이 단순한 목표를 수천억~수조 개의 문장으로 반복 학습하면, 문법·상식·논리적 흐름까지 습득하게 됨
- 이것이 "사전학습(Pretraining)"

## 6. 사전학습 vs 파인튜닝

- **사전학습(Pretraining)**: 방대한 일반 텍스트로 "다음 단어 예측"을 학습 → 기초 언어능력 습득 (막대한 자원 필요)
- **파인튜닝(Fine-tuning)**: 사전학습된 모델을 특정 목적(대화, 지시 따르기 등)에 맞게 추가 학습 → 상대적으로 적은 자원으로 가능
- ChatGPT/Claude 같은 서비스는 사전학습 + 대화형 파인튜닝(RLHF 등)을 거친 결과물

## 7. 추론(Inference)이란

- 학습이 끝난 모델에 새로운 입력을 주고 출력을 받는 과정 (우리가 챗봇과 대화할 때 일어나는 일)
- 학습(Training)과 추론(Inference)은 구분되는 단계 — 학습은 무겁고 비용이 크지만, 추론은 상대적으로 가벼움

## 8. 왜 상용 LLM은 개인이 못 만드는가

| 항목 | 미니 LLM (학습용) | 상용 LLM (GPT/Claude급) |
|---|---|---|
| 파라미터 수 | 수십만~수백만 | 수천억~수조 |
| 학습 데이터 | 텍스트 파일 1개 (MB급) | 인터넷 전체 규모 (TB~PB급) |
| GPU | 개인 GPU 1대 또는 Colab | 수천 대, 수주간 |
| 비용 | 무료~수만 원 | 수백억~수천억 원 |
| 목적 | 원리 이해 | 실용 서비스 |

→ **원리를 이해하는 것과 실용 모델을 만드는 것은 완전히 다른 규모의 문제**. 다음 단계(nanoGPT 실습)에서는 원리 이해에 집중합니다.
