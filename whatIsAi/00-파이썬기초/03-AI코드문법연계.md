# 코드 리뷰 전 필요한 파이썬 기초 문법

`02-실습`의 `model.py`, `train.py`, `generate.py`에서 실제로 쓰인 문법만 골라서 정리했다.
각 항목은 "문법 설명 → 우리 코드에서 쓰인 위치 → 간단 예시" 순서로 구성.

---

## 1. 들여쓰기(indentation)가 곧 블록 구분

파이썬은 `{ }` 대신 **들여쓰기(보통 스페이스 4개)**로 코드 블록을 구분한다. 들여쓰기가 한 칸이라도 틀리면 에러.

```python
def forward(self, x):
    B, T, C = x.shape          # 이 줄부터 함수 본문 (들여쓰기 4칸)
    k = self.key(x)
```
`model.py:29~31`. `def forward(self, x):` 콜론(`:`) 다음 줄부터, 같은 들여쓰기 깊이인 줄들이 하나의 블록이다.

## 2. 주석(`#`)과 문서화 문자열(`""" """`)

- `#` 뒤는 한 줄 주석.
- 함수/클래스 정의 바로 아래 `"""..."""`(삼중 인용부호)는 **docstring** — 그 함수/클래스가 뭘 하는지 설명하는 공식 문서 문자열. `help(함수명)`으로 조회 가능.

```python
class Head(nn.Module):
    """셀프 어텐션 헤드 1개.
    ...
    """
```
`model.py:13~18`

## 3. `import` / `from ... import ...`

```python
import torch
import torch.nn as nn                 # 별칭(as)으로 짧게 부르기
from torch.nn import functional as F   # 모듈 안의 특정 이름만 가져오기
from model import MiniGPT              # 우리가 만든 model.py에서 클래스 가져오기
```

`model.py:8~10`, `train.py:9`. `from model import MiniGPT`가 가능한 이유는 `model.py`가 같은 폴더에 있는 파이썬 모듈이기 때문 (파일명 `model.py` = 모듈명 `model`).

## 4. 변수 선언 — 타입을 미리 안 적어도 됨

```python
n_embd = 128        # int
learning_rate = 3e-4  # float (3.0 × 10⁻⁴)
device = "cpu"       # str
```
`train.py:17~18, 23`. 자바/C# 처럼 `int n_embd = 128;`가 아니라 그냥 대입만 하면 됨. 파이썬이 값을 보고 타입을 알아서 정한다(동적 타이핑).

## 5. 함수 정의와 여러 값 반환

```python
def forward(self, idx, targets=None):
    ...
    return logits, loss
```
`model.py:118, 135`

- `targets=None`: **기본값 매개변수**. `targets`를 안 주면 자동으로 `None`이 들어감 → 아래에서 `if targets is None:`으로 분기 가능.
- `return logits, loss`: 파이썬은 함수가 값을 **여러 개** 반환할 수 있다. 실제로는 `(logits, loss)`라는 튜플 하나를 반환하는 것이고, 호출하는 쪽에서 `logits, loss = model(x, y)`처럼 **한 번에 풀어서(unpack)** 받는다. (`train.py:65, 86`)

## 6. f-string — 문자열 안에 변수 바로 끼워넣기

```python
print(f"디바이스: {device}")
print(f"[{it:5d}/{max_iters}] train loss {losses['train']:.4f}")
```
`train.py:42, 80`

- `f"..."`에서 `{변수}`는 그 값으로 바로 치환됨.
- `{it:5d}`: 정수를 최소 5자리로, 앞을 공백으로 채워서 출력 (자릿수 정렬용).
- `{losses['train']:.4f}`: 소수점 4자리까지 출력.
- `{len(text):,}`: 천 단위마다 쉼표 삽입 (`1115394` → `1,115,394`).

## 7. 조건부 표현식 (한 줄 if-else, "삼항 연산자" 대체)

```python
device = "cuda" if torch.cuda.is_available() else "cpu"
d = train_data if split == "train" else val_data
```
`train.py:23, 51`

읽는 순서: **"cuda" (만약) `if 조건` (이면) 아니면(`else`) "cpu"**. 자바/C#의 `조건 ? A : B`와 동일한 역할이지만 파이썬은 `A if 조건 else B` 순서로 쓴다.

## 8. 리스트 / 튜플 / 딕셔너리 — 자료구조 3종

```python
chars = sorted(list(set(text)))   # 리스트: [ ]
context = torch.zeros((1, 1))     # 튜플: ( )  — 리스트와 비슷하지만 수정 불가(immutable)
stoi = {ch: i for i, ch in enumerate(chars)}  # 딕셔너리: { key: value }
```
`train.py:35, 37, 81`

- **리스트** `[ ]`: 순서 있는 값들의 모음, 값 추가/변경 가능
- **튜플** `( )`: 리스트와 비슷하지만 한 번 만들면 내용을 바꿀 수 없음. 텐서 shape 지정(`(1, 1)`)처럼 "고정된 값 묶음"에 자주 씀
- **딕셔너리** `{ }`: `키: 값` 쌍의 모음. `stoi["a"]`처럼 키로 값을 조회 (자바의 `HashMap`, `Map`과 동일한 개념)

---

## 9. 컴프리헨션(comprehension) — for 루프를 한 줄로 축약

가장 낯설 수 있는 문법. "리스트/딕셔너리를 만드는 for 루프"를 한 줄로 쓰는 방식이다.

```python
# 딕셔너리 컴프리헨션
stoi = {ch: i for i, ch in enumerate(chars)}
```
`train.py:37`. 풀어서 쓰면:
```python
stoi = {}
for i, ch in enumerate(chars):
    stoi[ch] = i
```
`enumerate(chars)`는 `(0, chars[0]), (1, chars[1]), ...`처럼 **인덱스와 값을 동시에** 내주는 함수.

```python
# 리스트 컴프리헨션
self.heads = nn.ModuleList([Head(n_embd, head_size, block_size, dropout) for _ in range(n_head)])
```
`model.py:54~56`. 풀어서 쓰면:
```python
heads_list = []
for _ in range(n_head):
    heads_list.append(Head(n_embd, head_size, block_size, dropout))
self.heads = nn.ModuleList(heads_list)
```
`_`는 "이 반복 변수는 실제로 안 쓴다"는 관례적 이름 (몇 번째인지 중요하지 않고 그냥 4번 반복만 하고 싶을 때).

또 다른 예:
```python
x = torch.stack([d[i:i + block_size] for i in ix])
```
`train.py:53` — `ix`에 들어있는 각 인덱스 `i`마다 `d[i:i+block_size]`(슬라이싱, 아래 11번 참고)를 뽑아 리스트로 만들고, `torch.stack`으로 하나의 텐서로 합침.

## 10. 언패킹(unpacking) — 여러 값을 한 번에 여러 변수로

```python
B, T, C = x.shape                 # model.py:30
stoi, itos = ckpt["stoi"], ckpt["itos"]   # generate.py:18
```

`x.shape`가 `(32, 64, 128)`이라는 튜플을 반환하면, `B, T, C = x.shape`는 `B=32, T=64, C=128`을 한 줄로 동시에 할당하는 것. 오른쪽 값의 개수와 왼쪽 변수 개수가 정확히 맞아야 한다.

`**cfg` 형태의 언패킹도 있다:
```python
model = MiniGPT(ckpt["vocab_size"], **cfg).to(device)
```
`generate.py:22`. `cfg`가 `{"n_embd": 128, "n_head": 4, ...}`인 딕셔너리라면, `**cfg`는 이걸 `n_embd=128, n_head=4, ...`처럼 **키워드 인자로 펼쳐서** 전달한다. 즉 `MiniGPT(vocab_size, n_embd=128, n_head=4, n_layer=4, block_size=64, dropout=0.1)`을 호출하는 것과 같음 — 함수 시그니처와 딕셔너리 키 이름이 정확히 일치해야 동작.

함수 호출 시 리스트를 펼치는 `*`도 있다:
```python
self.blocks = nn.Sequential(*[Block(n_embd, n_head, block_size, dropout) for _ in range(n_layer)])
```
`model.py:112~114`. `[Block(...), Block(...), Block(...), Block(...)]`라는 리스트(4개)를 `*`로 풀어서 `nn.Sequential(Block(...), Block(...), Block(...), Block(...))`처럼 인자 4개를 따로 전달하는 것과 같아짐. (`nn.Sequential`은 리스트 하나를 통째로 받지 않고, 여러 층을 인자로 하나씩 받는 API라서 이렇게 풀어줘야 함)

## 11. 슬라이싱(slicing) — `[시작:끝:간격]`

리스트, 튜플, 문자열, 텐서 모두 공통으로 쓸 수 있다.

```python
train_data = data[:n]        # 처음부터 n번째(제외) 까지
val_data = data[n:]          # n번째부터 끝까지
idx_cond = idx[:, -self.block_size:]   # model.py:141
```

- `data[:n]`: `시작 생략 = 맨 처음부터`
- `data[n:]`: `끝 생략 = 맨 끝까지`
- `idx[:, -self.block_size:]`: 텐서가 2차원(`(B, T)`)일 때, `:`는 "첫 번째 차원(배치)은 전부 다", `-self.block_size:`는 "두 번째 차원(시퀀스)의 뒤에서부터 block_size개만" — **음수 인덱스는 "끝에서부터 몇 번째"**를 의미 (`-1`=마지막, `-64`=끝에서 64번째).

```python
logits = logits[:, -1, :]   # model.py:143
```
3차원 텐서 `(B, T, vocab_size)`에서 "배치는 전부, 시퀀스는 마지막 위치만, vocab 차원은 전부" → 결과 shape `(B, vocab_size)`.

## 13. 클래스와 상속, `self`, `super()`

```python
class Head(nn.Module):
    def __init__(self, n_embd, head_size, block_size, dropout):
        super().__init__()
        self.key = nn.Linear(n_embd, head_size, bias=False)

    def forward(self, x):
        ...
```
`model.py:13, 20~24, 29`

- `class Head(nn.Module):` → `Head`는 `nn.Module`을 **상속**한다. PyTorch의 모든 신경망 층/모델은 `nn.Module`을 상속해야 텐서 연산, GPU 이동, 파라미터 관리 같은 기능을 공짜로 물려받는다.
- `__init__`: 클래스의 **생성자**. `Head(128, 32, 64, 0.1)`처럼 객체를 만들 때 자동으로 호출되어 필요한 값들을 준비.
- `self`: "지금 만들어지고 있는 이 객체 자신"을 가리키는 참조. 자바/C#의 `this`와 동일. `self.key = ...`는 "이 객체의 `key`라는 속성에 저장" 의미.
- `super().__init__()`: 부모 클래스(`nn.Module`)의 생성자를 먼저 실행. 이걸 빼먹으면 PyTorch 내부 초기화가 안 돼서 `self.key = ...` 같은 등록이 제대로 동작하지 않음.
- `forward(self, x)`: 이 객체가 `호출될 때`(예: `head(x)`) 실행되는 로직. `nn.Module`을 상속하면 `객체(입력)`처럼 함수처럼 호출할 때 내부적으로 `forward`가 실행되도록 이미 구현되어 있음.

## 14. 데코레이터(`@`) — 함수를 감싸는 문법

```python
@torch.no_grad()
def generate(self, idx, max_new_tokens):
    ...
```
`model.py:137~138`, `train.py:57`

`@torch.no_grad()`는 바로 아래 함수 전체를 "그래디언트(기울기) 계산 없이 실행"하도록 감싸주는 장치. 학습(backpropagation)이 필요 없는 순수 추론/평가 코드에서 메모리와 연산을 아끼기 위해 붙인다. `@`로 시작하는 줄은 항상 바로 아래에 있는 함수/메서드에 적용된다.

## 15. `with` 문 — 자동으로 정리(cleanup)까지 해주는 블록

```python
with open(DATA_PATH, "r", encoding="utf-8") as f:
    text = f.read()
```
`train.py:31~32`

파일을 열고(`open`) 다 쓰면 반드시 닫아줘야(`close`) 하는데, `with`문을 쓰면 블록이 끝나는 순간(에러가 나도!) 자동으로 파일을 닫아준다. `f.close()`를 직접 안 써도 됨.

## 16. `if __name__ == "__main__":`

```python
if __name__ == "__main__":
    main()
```
`train.py:107~108`, `generate.py:35~36`

파이썬 파일을 **직접 실행**했을 때만(`python train.py`) 이 블록이 돌아가고, 다른 파일에서 `import train`처럼 **불러오기만** 했을 때는 실행되지 않게 막는 관례적 코드. `__name__`은 "직접 실행된 파일이면 `"__main__"`, 불러와진 모듈이면 파일 이름"이 자동으로 담기는 특수 변수.

## 17. `sys.argv` — 커맨드라인 인자 받기

```python
n_tokens = int(sys.argv[1]) if len(sys.argv) > 1 else 500
prompt = sys.argv[2] if len(sys.argv) > 2 else ""
```
`generate.py:13~14`

터미널에서 `python generate.py 300 "ROMEO:"`처럼 실행하면:
- `sys.argv[0]` = `"generate.py"` (스크립트 이름, 항상 0번)
- `sys.argv[1]` = `"300"` (문자열이라서 `int()`로 형변환 필요)
- `sys.argv[2]` = `"ROMEO:"`

인자를 안 주면 `sys.argv`에 해당 항목이 없으므로, `len(sys.argv) > 1` 같은 조건으로 안전하게 기본값(`500`, `""`)을 쓰도록 처리.

## 18. `_` (밑줄) 관례 — "이 값은 관심 없음"

```python
for _ in range(n_head):        # 반복 횟수만 필요, 반복 변수 값은 안 씀
_, loss = model(x, y)          # 반환값 중 첫 번째(logits)는 지금 안 씀
```
`model.py:55`(컴프리헨션 내부), `train.py:65`

문법적으로는 그냥 평범한 변수 이름이지만, "이 자리의 값은 쓸 일이 없다"는 의도를 코드 읽는 사람에게 알려주는 파이썬 커뮤니티의 관례.
