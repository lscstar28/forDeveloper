# 0단계 - 공통 기초

모든 개발 분야에 필요한 최소 공통 기술.

## 개발 환경 / 도구

- [ ] 터미널/셸 기본 사용법 (참고: [../shell-study](../shell-study))
- [ ] Git 기본 (clone, add, commit, push, pull, branch, merge) — 참고: [../git-study](../git-study)
- [ ] Git 협업 워크플로 (PR, rebase, conflict 해결, .gitignore)
- [ ] 코드 에디터 (VS Code) 단축키/확장 활용

## 컴퓨터 공통 지식

- [ ] 네트워크 기초 (HTTP/HTTPS, DNS, TCP/IP, 포트)
- [ ] 클라이언트-서버 구조 이해
- [ ] 운영체제 기초 (프로세스, 파일 시스템, 환경변수)

## 프로그래밍 기본기

- [ ] 변수, 자료형, 제어문, 함수 등 프로그래밍 공통 개념
- [ ] 자료구조 기초 (배열, 객체/맵, 스택/큐)
- [ ] 알고리즘 기초 (정렬, 탐색, 시간복잡도 개념)
