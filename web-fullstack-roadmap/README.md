# 웹 풀스택 학습 로드맵

기초부터 실무 수준까지 단계별로 정리한 기술 목록. 각 단계 파일에 기술 목록과 학습 순서가 정리되어 있음.

## 단계 구성

| 단계 | 파일 | 주제 |
|---|---|---|
| 0 | [00-foundation.md](./00-foundation.md) | 프로그래밍/개발 공통 기초 (Git, 터미널, 네트워크) |
| 1 | [01-frontend-basics.md](./01-frontend-basics.md) | HTML/CSS/JavaScript 기초 |
| 2 | [02-frontend-advanced.md](./02-frontend-advanced.md) | TypeScript, 프론트엔드 프레임워크, 빌드 도구 |
| 3 | [03-backend-basics.md](./03-backend-basics.md) | 서버 언어/런타임, API 설계 |
| 4 | [04-database.md](./04-database.md) | SQL/NoSQL, ORM |
| 5 | [05-infra-devops.md](./05-infra-devops.md) | Docker, CI/CD, 클라우드, 배포 |
| 6 | [06-advanced.md](./06-advanced.md) | 테스트, 성능, 아키텍처, 보안 |

## 진행 방식

- 각 파일은 `[ ] 기술명` 체크리스트 형태 → 학습 완료 시 `[x]`로 체크하며 진행 상황 추적
- 순서는 권장 순서이며, 이미 알고 있는 항목은 건너뛰어도 됨
- 관련 실습은 워크스페이스 내 별도 폴더로 분리 (예: [../typescript-study](../typescript-study), [../shell-study](../shell-study), [../git-study](../git-study))
